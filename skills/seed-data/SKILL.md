# Seed-данные

## Цели

- `assets/seed/ingredients.json` — ≥ 250 продуктов домашней кухни.
- `assets/seed/recipes.json` — ≥ 120 рецептов русской и домашней кухни, все типы из `spec/data/enums.json`, все три сложности.

Формат — `spec/data/seed_examples/` (там по несколько эталонных записей). Категории продуктов — `spec/data/ingredient_categories.json`.

## Продукты

- `id` — стабильный slug латиницей: `potato`, `chicken_fillet`. Не менять после релиза.
- `name` — как говорят дома: «картофель». `synonyms` — разговорные и падежные формы: «картошка», «картошку», «картофелина».
- `parent_id` — для иерархии: `chicken_fillet` → `chicken`; `walnut` → `nuts`; `champignon` → `mushrooms`. Аллергии и исключения работают через иерархию.
- `is_staple: true` — только соль, вода, сахар, чёрный перец, подсолнечное масло. Не больше.

## Рецепты

- Можно сгенерировать ИИ скриптом `tool/gen_seed.dart` (опционально), но:
  1. каждый рецепт проходит `RecipeValidator` (тест `seed_recipes_valid_test`);
  2. каждый `ingredient_id` есть в `ingredients.json` (тест `seed_refs_test`);
  3. нет дублей по `normalized_title` и по Жаккару ≥ 0.8 (тест `seed_no_duplicates_test`);
  4. 20 случайных рецептов владелец проверяет руками — список выведи в отчёт этапа 1.
- Распределение (ориентир): супы 20, вторые 35, гарниры 12, салаты 15, завтраки 12, выпечка 10, десерты 10, закуски 6.
- Шаги короткие: ≤ 2 предложения, глагол в начале («Нарежьте лук кубиками»).
- `timer_seconds` — у каждого шага с ожиданием (варить, тушить, запекать, остудить).

## Источник правды

Seed — стартовая база. Пользовательские данные (оценки, избранное, свои рецепты) живут в БД и при обновлении seed не перезаписываются.
