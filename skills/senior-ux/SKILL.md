# Адаптивный интерфейс: просто для одних, полно для других

Приложением пользуются разные люди: пожилые, родители, молодые. Решение D-057: один код, два готовых режима и тонкая настройка. Каждый экран проверяй двумя вопросами: «Поймёт ли бабушка в режиме „Просто“, что нажать, без подсказки?» и «Найдёт ли опытный пользователь в режиме „Полный“ всё, что ему нужно, без лишних нажатий?»

## Как устроено

- Все размеры, плотность, видимость элементов берутся из `AdaptiveSpec` (провайдер `uiProfileProvider`). Никаких `if (mode == …)` по экранам и никаких захардкоженных размеров: только `Theme.of(context)` и `context.adaptive`.
- Новый элемент обязан работать в обоих режимах. Если в «Просто» он лишний — он скрывается через `AdaptiveSpec`, а не удаляется.

## В любом режиме (обязательно)

- Контраст текста ≥ 4.5:1 в светлой и тёмной теме.
- `Semantics` с осмысленным label на всех интерактивных элементах.
- Всё, что видно, нажимается и что-то объясняет или открывает.
- Любое действие жестом (свайп, долгое нажатие) дублируется видимой кнопкой.
- Удаление и «Не хочу такое» — мягко, snackbar «Отменить» 5 с.
- Ошибки человеческим языком, без кодов и английских слов.
- Тексты только из ARB. Учитывать системный размер шрифта телефона.
- Загрузка ИИ не блокирует экран: локальные результаты сразу, карточки помощника появляются ниже по ходу списка (R8-08), не сдвигая видимое.

## Режим «Просто»

- Текст ≥ 18 sp, заголовки 24 sp, режим готовки 28 sp. Зона нажатия ≥ 56×56 dp, между кнопками ≥ 8 dp.
- У каждой иконки подпись текстом.
- Одно главное действие на экране — крупная заполненная кнопка.
- Не больше одного ряда фильтров-чипов; не больше 4 вкладок на нижней панели.
- Без меню «три точки» для важного, без мелких чекбоксов, без цифр-весов и техники ИИ.
- Статистика — 4 крупные плитки, без сложных графиков.

## Режим «Полный»

- Текст ≥ 14 sp (тело 16 sp), зона нажатия ≥ 48×48 dp, плотнее карточки (сетка 2 колонки на широких экранах).
- Доступны: панель фильтров (несколько сразу), сортировка, поиск на всех списках, свайпы на карточках (с дублем кнопкой), массовые действия, полная статистика с графиками, подробности ИИ (модель, время ответа).
- Нижняя панель до 5 вкладок.

## Проверка экрана перед закрытием задачи

1. Оба режима × шрифт системы 1.0 и 2.0 × светлая и тёмная тема — ничего не обрезается, нет overflow (`overflow_all_screens_test`).
2. Виджет-тест: главная кнопка находится по тексту и нажимается в обоих режимах.
3. Golden-скриншот экрана в обоих режимах в `docs/reports/img/`.

## Чего не делать

- Не показывать настройки ИИ, ключи, адреса на основных экранах ни в одном режиме.
- Не делать онбординг из нескольких экранов: один экран выбора режима, пропускаемый.
- Не переключать режим автоматически без согласия пользователя — только предлагать.
