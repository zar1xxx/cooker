# Установка и настройка (для внука)

> Черновик. Исполнитель дописывает его на этапе 6 (задача S6-04) — со скриншотами экранов настроек.

## 1. Установить приложение на телефон

1. Скопировать `chto-prigotovit.apk` на телефон бабушки.
2. Открыть файл, разрешить установку из этого источника, установить.
3. Запустить один раз — приложение сразу работает на встроенных рецептах, без настроек.

## 2. Домашний ПК с LM Studio (основной ИИ)

1. В LM Studio загрузить instruct-модель от 7B, которая поддерживает структурированный вывод (JSON Schema). Модели меньше 7B с ним часто не справляются.
2. Вкладка **Developer** → запустить сервер (порт 1234) → включить **Serve on Local Network**.
3. В Windows: «Параметры → Сеть и Интернет → Wi-Fi → свойства сети» → тип **Частная**.
4. Открыть порт: PowerShell **от администратора** → `C:\dev\cooker\tool\firewall_lmstudio.ps1`.
5. Проверить с самого ПК: `tool\lmstudio_ping.ps1` — должен вывести список моделей и тестовый JSON-ответ.
6. На телефоне (в том же Wi-Fi): настройки приложения → **Найти компьютер** → выбрать модель → **Проверить связь**.

Чтобы ПК находился всегда по одному адресу, можно закрепить за ним IP в настройках роутера (DHCP-резервирование). Приложение и без этого найдёт ПК заново, но медленнее.

## 3. GigaChat (запасной ИИ, когда ПК выключен)

1. Зарегистрироваться на developers.sber.ru (Сбер ID) → создать проект GigaChat API для физлиц.
2. Скопировать **ключ авторизации** (Authorization key).
3. На ПК можно проверить ключ: `$env:GIGACHAT_AUTH_KEY="<ключ>"; tool\gigachat_ping.ps1`.
4. На телефоне: настройки приложения → GigaChat → вставить ключ → **Проверить связь**.
