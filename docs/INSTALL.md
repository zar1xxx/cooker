# Инструкция по установке и настройке («для внука»)

Это руководство предназначено для настройки приложения **«Что приготовить?»** на телефоне бабушки и подключения домашнего ПК (LM Studio) и резервного ИИ (GigaChat).

---

## 1. Установка приложения на телефон

### Вариант А: Через USB и компьютер (для разработчика)
1. Подключите телефон к компьютеру по USB с включённой «Отладкой по USB».
2. В терминале на ПК выполните:
   ```powershell
   cd C:\dev\cooker
   adb install -r build\app\outputs\flutter-apk\app-release.apk
   ```

### Вариант Б: Передача APK на телефон (без проводов)
1. Отправьте файл на телефон (через Telegram «Избранное», WhatsApp, Яндекс.Диск или по Bluetooth):
   - **Рекомендуемый файл:** `build\app\outputs\flutter-apk\app-arm64-v8a-release.apk` (**24.8 МБ**, оптимизирован под 64-битные современные процессоры Android ARMv8 — устанавливается быстрее и занимает меньше памяти).
   - **Универсальный файл:** `build\app\outputs\flutter-apk\app-release.apk` (66.5 МБ, включает библиотеки под все архитектуры).
2. На телефоне откройте загруженный APK-файл.
3. При запросе системы безопасности Android разрешите «Установку из неизвестных источников» для приложения, через которое открыт APK.
4. Нажмите «Установить».

> [!NOTE]
> Сразу после установки приложение готово к работе: встроенный каталог включает десятки проверенных домашних рецептов и базу продуктов. Подключение ИИ не является обязательным, бабушка может пользоваться приложением сразу и без интернета.

## 2. Домашний ПК с LM Studio (основной ИИ)

В локальной сети Wi-Fi приложение автоматически обращается к домашнему ПК. Запросы бесплатны, не требуют интернета и обрабатываются локально.

### Быстрый способ: один ярлык на рабочем столе

Всё ниже (шаги 2.2–2.3 и QR-подключение) делает ярлык **«Связать телефон с ПК»** на рабочем столе ПК. Дважды щёлкните его:
1. открывается порт 1235 в брандмауэре (при первом запуске Windows спросит разрешение — нажмите «Да»);
2. запускается сервер LM Studio для домашней сети;
3. загружается модель `ornith-1.5-35b-a3b` (контекст 8192, parallel 2), если ещё не загружена;
4. в браузере открывается QR-код. На телефоне: «Настройки» → «Подключить компьютер по QR-коду» → наведите камеру.

Телефон должен быть в той же сети Wi-Fi, а сеть на ПК — «Частная». Если шаг не удался, окно покажет причину красным и не закроется.
Если ярлыка нет, запустите `tool\create_desktop_shortcut.bat`. Сам сценарий: `tool\connect_phone.ps1` (его же можно запустить через `tool\connect_phone.bat`).

### Шаг 2.1. Требования к модели
1. Установите [LM Studio](https://lmstudio.ai/) на домашний компьютер.
2. В строке поиска LM Studio скачайте `instruct`-модель размером **от 7B параметров** (например, `Qwen2.5-7B-Instruct-GGUF` или `Llama-3.1-8B-Instruct-GGUF`).
   > [!IMPORTANT]
   > Модели меньше 7B параметров часто делают ошибки в формате JSON Schema и бракуются валидатором безопасности.

### Шаг 2.2. Загрузка модели и запуск локального сервера

> [!WARNING]
> **Причина медленной работы и таймаутов LM Studio:**
> Если в памяти LM Studio загружено несколько копий одной модели (например, дубликаты `:2`, `:3`) или задан избыточный контекст (например, 262 144 токена при `parallel 4`), видеопамять переполняется, вычисления сбрасываются в оперативную память (RAM), и генерация замедляется в сотни раз (вплоть до таймаута 180 секунд даже на коротких запросах).
> 
> **Рекомендация по быстрой работе:**
> 1. В памяти должна быть **ровно одна копия** модели.
> 2. Размер контекста должен быть ограничен: **8192 токена** (этого с избытком хватает для схем блюд и меню, а ответ занимает 0.5–10 секунд).
> 3. Проверьте запущенные модели:
>    ```cmd
>    lms ps
>    ```
> 4. Если моделей несколько или контекст велик, выгрузите всё и загрузите одну модель с контекстом 8192:
>    ```cmd
>    lms unload --all
>    lms load google/gemma-4-12b-qat --context-length 8192
>    ```
>    *(флаг `--context-length` / `-c` задаёт контекст, `--gpu max` включает полное ускорение на GPU).*

1. Запустите локальный сервер через готовый командный файл проекта:
   ```cmd
   tool\start_lmstudio_server.bat
   ```
   Скрипт останавливает зависшие инстансы сервера, запускает сервер на порту **1235** с параметром `--bind 0.0.0.0`, чтобы слушать всю локальную сеть (порт 1234 на ПК может быть занят другими службами), и проверяет доступность моделей через API.
   *(Кнопку Start Server в интерфейсе режима разработчика использовать не нужно).*

### Шаг 2.3. Настройка сети Windows и брандмауэра
1. Откройте «Параметры Windows» → «Сеть и Интернет» → «Wi-Fi» → нажмите на текущую сеть → установите тип **Частная сеть**.
2. Откройте PowerShell **от имени администратора** и выполните готовый скрипт проекта:
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\dev\cooker\tool\firewall_lmstudio.ps1
   ```
   Этот скрипт откроет входящие TCP-порты 1234 и 1235 для профиля «Частная сеть».
   Также можно добавить правило вручную в командной строке администратора:
   ```cmd
   netsh advfirewall firewall add rule name="LM Studio 1235" dir=in action=allow protocol=TCP localport=1235 profile=private
   ```
3. Проверьте работу сервера с самого ПК:
   ```powershell
   dart run tool/ai_smoke.dart
   ```
   Скрипт проверит порты 1234 и 1235, подключится к LM Studio, проверит генерацию подборки и рецепта через `RecipeValidator`.

### Шаг 2.4. Если компьютер отвечает медленно

Если генерация подборки или рецепта занимает больше 15–30 секунд, либо в `ai_smoke` появляется предупреждение `«Видеопамяти не хватает: см. docs/INSTALL.md раздел 2.4»`:

#### 1. Причина — переполнение видеопамяти (VRAM)
Когда веса модели, KV-кэш контекста для нескольких параллельных слотов и сторонние приложения (браузеры, IDE, мессенджеры) суммарно превышают физический объём памяти видеокарты (например, 10 ГБ на RTX 3080), видеодрайвер перемещает часть данных в общую оперативную память (Shared GPU Memory / RAM). Скорость генерации при этом мгновенно падает с 30–50 токенов/с до 0.1–0.5 токенов/с (в сотни раз), приводя к таймаутам.

#### 2. Как проверить видеопамять
Запустите командный файл диагностики видеокарты и LM Studio:
```cmd
tool\gpu_diag.bat
```
Отчёт сохранится в `docs\reports\last_gpu_diag.txt`. В нём:
- В блоке `nvidia-smi` проверьте строку памяти: `memory.used` не должно вплотную приближаться к `memory.total` (желательно иметь запас $\ge 1.5$–$2$ ГБ свободной видеопамяти).
- В блоке `processes using gpu` проверьте, какие процессы занимают память видеокарты.
- В блоке `lms ps` проверьте параметры загруженной модели (размер контекста `CONTEXT` и число параллельных слотов `PARALLEL`).

#### 3. Что сделать для восстановления скорости:
1. **Оставить ровно одну копию модели:**
   Выгрузите все копии моделей из памяти:
   ```cmd
   lms unload --all
   ```
2. **Загрузить модель с контекстом 4096 и 1 параллельным слотом:**
   (Параметры проверены по `lms load --help`):
   ```cmd
   lms load ornith-1.5-35b-a3b -c 4096 --parallel 1
   ```
   Флаг `-c 4096` (или `--context-length 4096`) в 2–4 раза сокращает объём KV-кэша, а `--parallel 1` предотвращает резервирование видеопамяти под неиспользуемые одновременные слоты.
3. **Закрыть тяжёлые программы, использующие видеокарту:**
   Закройте игры, 3D-приложения, тяжёлые вкладки браузера (видео 4K, WebGL) или отключите аппаратное ускорение в фоновых программах.
4. **Если видеопамяти всё равно не хватает — переключиться на модель меньшего размера:**
   - Рекомендуемая модель **`ornith-1.5-35b-a3b`** (MoE): занимает ~3.6–4.0 ГБ видеопамяти (остальное держит в быстрой RAM) и выдаёт 40–50 ток/с при высоком качестве ответов.
   - Более лёгкая альтернатива **`ornith-1.5-9b`**: занимает всего 5.8 ГБ видеопамяти и работает со скоростью ~85 ток/с:
     ```cmd
     lms unload --all
     lms load ornith-1.5-9b -c 4096 --parallel 1
     ```
   После изменения модели перезапустите сервер `tool\start_lmstudio_server.bat` и выполните проверку через `tool\run_ai_smoke.bat`.

> [!TIP]
> Чтобы IP-адрес компьютера не менялся при перезагрузках роутера, закрепите за ПК постоянный IP в настройках роутера (DHCP Reservation).

## 3. Резервный ИИ — GigaChat API (когда ПК выключен)

Если компьютер выключен или бабушка находится не дома (на даче, в магазине, в мобильной сети 4G/LTE), приложение автоматически переключается на облачный GigaChat.

1. Перейдите на [developers.sber.ru](https://developers.sber.ru/) и авторизуйтесь по Сбер ID.
2. Создайте проект **GigaChat API для физических лиц** (бесплатный пакет включает 250 млн токенов в год, чего хватает более чем на 100 000 рецептов).
3. В панели проекта скопируйте **Ключ авторизации** (Authorization Key в Base64).
4. Проверить ключ на компьютере можно скриптом:
   ```powershell
   $env:GIGACHAT_AUTH_KEY="<ваш_ключ>"
   powershell -ExecutionPolicy Bypass -File C:\dev\cooker\tool\gigachat_ping.ps1
   ```

## 4. Как открыть экран настроек на телефоне

Интерфейс приложения адаптирован для пожилых людей, поэтому технические настройки скрыты от случайных нажатий:

1. Откройте вкладку **«Сегодня»** или **«Что есть дома»**.
2. **Зажмите заголовок «Что приготовить?» в верхней панели на 2 секунды (долгое нажатие).**
3. Откроется инженерный экран «Настройки ИИ и системы».

### Подключение к ПК:
1. В блоке «LM Studio на ПК» нажмите крупную кнопку **«Найти компьютер»**. Приложение просканирует локальную сеть Wi-Fi и автоматически подставит IP-адрес ПК.
2. Нажмите **«Обновить список»** в поле выбора модели и выберите загруженную в LM Studio модель.
3. Нажмите **«Проверить связь»** — появится зелёный статус «ПК доступен».

### Сохранение ключа GigaChat:
1. Вставьте скопированный ключ авторизации в поле «Ключ авторизации GigaChat».
2. Нажмите **«Сохранить ключ»**.
   > [!NOTE]
   > Ключ надёжно шифруется аппаратно через Android Keystore (`flutter_secure_storage`) и никогда не попадает в логи или файлы резервных копий.
3. Нажмите **«Проверить связь»** для GigaChat — появится зелёный статус «GigaChat подключён».

### Ежедневное напоминание меню дня:
- В нижней части экрана настроек можно включить ежедневное напоминание (по умолчанию выключено).
- Выберите комфортное для бабушки время (например, 10:00 утра).

## 5. Профиль вкусов и ограничения

Из экрана «Настройки ИИ» по ссылке **«Что приложение знает о ваших вкусах»** доступен экран управления предпочтениями:

1. **Любимые и нелюбимые признаки:** приложение само запоминает, что бабушка готовит чаще и чему ставит высокие оценки (4–5 звёзд), а что пропускает или бракует (1–2 звезды).
2. **Аллергии:** выберите или найдите ингредиенты, которые категорически нельзя употреблять (например, «орехи», «мёд»). Блюда с ними гарантированно исключаются как из каталога, так и из генераций ИИ по всей иерархии продуктов.
3. **Исключения («не ем»):** продукты, которые бабушка просто не любит (например, «лук», «баклажаны»).
4. **Кнопка «Сбросить вкусы»:** очищает историю оценок и возвращает нейтральные веса при необходимости.

## 6. Резервная копия и перенос данных

Чтобы при смене телефона или переустановке сохранить историю готовки, любимые рецепты и настройки:

1. В экране настроек нажмите **«Резервная копия»**.
2. **Создание копии:** нажмите **«Скопировать в буфер»** (размер дампа ~20–50 КБ) и сохраните текст в заметки или отправьте сообщением.
   > [!IMPORTANT]
   > В файле резервной копии содержатся только рецепты, отметки запасов и история. Никаких паролей и API-ключей в копии нет.
3. **Восстановление:** на новом телефоне откройте этот же экран, вставьте текст JSON в поле ввода и нажмите **«Восстановить данные»**. База данных будет атомарно восстановлена без потерь.

## 7. Решение возможных неполадок (FAQ)

| Проблема | Причина | Что проверить |
| --- | --- | --- |
| Индикатор «Офлайн (каталог)» на телефоне | Выключен Wi-Fi или не запущен LM Studio | Убедитесь, что телефон подключен к домашнему Wi-Fi, а в LM Studio горит зелёная кнопка «Stop Server» (сервер активен). |
| Ошибка соединения с ПК при верном IP | Брандмауэр Windows блокирует порт 1234 | Проверьте, что сеть в Windows имеет статус «Частная», и повторно запустите `tool/firewall_lmstudio.ps1` от администратора. |
| ИИ долго думает (> 60 сек) | Модель слишком тяжелая для видеокарты ПК | В настройках LM Studio увеличьте число слоёв, выгружаемых на GPU (`GPU Offload`), либо используйте более квантованную модель (Q4_K_M). |
| GigaChat выдает 401 Unauthorized | Истёк или неверно скопирован ключ | Создайте новый Authorization Key в кабинете разработчика Сбера и вставьте его заново. |
| Не слышно озвучивание рецепта | В системе Android отключен синтез речи | Установите или обновите «Речевые сервисы от Google» через Google Play и выберите русский голос по умолчанию. |

## 8. Ключ подписи приложения (Keystore)

Релизный APK подписан криптографическим сертификатом разработчика для защиты целостности приложения.

- **Файл хранилища ключей (Keystore):**  
  `C:\dev\cooker_keystore\upload-keystore.jks`  
  (сохранён вне репозитория для безопасности).
- **Файл конфигурации и паролей:**  
  `android/key.properties`  
  (содержит пароли `storePassword` и `keyPassword`, добавлен в `.gitignore` и намеренно не коммитится в систему контроля версий).

> [!CAUTION]
> **ОБЯЗАТЕЛЬНО СОХРАНИТЕ ЭТИ ДВА ФАЙЛА В НАДЁЖНОЕ МЕСТО!**  
> Скопируйте `upload-keystore.jks` и `android/key.properties` на отдельную защищённую флешку или в зашифрованный менеджер паролей.  
> **Без этого ключа невозможно выпустить и установить обновление поверх уже установленного у бабушки приложения.** В операционной системе Android подпись проверяется при каждом обновлении: если ключ будет утерян, обновить приложение можно будет только через полное удаление с потерей накопленной локальной истории и отметок.
