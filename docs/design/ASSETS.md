### Особенности

- **Иконки — плитки, а не прозрачные значки.** Каждая иконка уже лежит на кремовой подложке `#F2E6D0`-подобного цвета со скруглёнными углами (углы прозрачные). Подложка отлично читается и в светлой, и в тёмной теме. Значит, в виджете **не нужно** рисовать свою подложку под иконкой — только скругление совпадает (~10 % стороны).
- **Разрешение иконок 180 px** — хватает на 60 dp при плотности 3x. Крупнее 60 dp не растягивать; нужно крупнее — перегенерировать.
- **Заглушки и состояния ~530 px по ширине** — для полноэкранного показа мягковаты. Для первого релиза годятся; при перегенерации — 1600×900 по промпту.
- **Иконка приложения** сделана из варианта на зелёном фоне: на светлом белый пар-«вопрос» не виден. Цвет фона иконки — `#226440` (из картинки), он чуть светлее основного `#1E5B3A` — это нормально.

## Чего не хватает (перегенерировать по `IMAGE_PROMPTS.md`)

| Элемент | Причина |
| --- | --- |
| `states/pantry_empty` | В присланной картинке на записке в холодильнике искажённый текст («Приглате зевавить продуйте!») — текста на картинках быть не должно |
| `states/missing_few` | Присланная картинка (банки в корзине) подписана как «В кладовой пусто» и не подходит по смыслу |
| `states/history_empty`, `calendar_empty`, `cooking_done`, `rate_dish`, `offline`, `ai_thinking`, `pc_search`, `pc_found`, `pc_not_found` | Не присылались |
| `placeholders/breakfast`, `snack`, `baking`, `dessert`, `drink`, `preserve` | Не присылались (до появления — брать иконку типа блюда крупно на кремовом фоне) |
| `icons/ingredients/*` (≈40 продуктов) | Не присылались (до появления — иконка категории продукта) |
| `icons/difficulty/hat_*` | Лучше нарисовать вектором (ТЗ 7.2) |
| `branding/play_feature.png` | Нужна только для публикации |
