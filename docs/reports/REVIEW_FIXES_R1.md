## Как запустить и проверить вручную

1. Полный цикл автоматических проверок:
   ```powershell
   cd C:\dev\cooker
   powershell -ExecutionPolicy Bypass -File tool\check.ps1
   ```
2. Запуск автотестов качества рецептов и графических ассетов:
   ```powershell
   flutter test test/seed_quality_test.dart test/app_images_test.dart test/screenshots_test.dart
   ```
3. Сборка сплит-релизов:
   ```powershell
   flutter build apk --release --split-per-abi
   ```
   Готовые файлы: `build\app\outputs\flutter-apk\app-arm64-v8a-release.apk` (24.8 МБ), `app-armeabi-v7a-release.apk` (22.6 МБ), `app-x86_64-release.apk` (26.2 МБ).
4. Проверка криптографической подписи APK:
   ```powershell
   $env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
   $apksigner = Get-ChildItem -Recurse -Filter "apksigner.bat" "C:\Android\sdk" | Select-Object -First 1 -ExpandProperty FullName
   & $apksigner verify --verbose "build\app\outputs\flutter-apk\app-arm64-v8a-release.apk"
   ```
