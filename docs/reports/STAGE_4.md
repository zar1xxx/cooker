## Как запустить и проверить вручную

1. Сборка проекта и прогон тестов:
   ```powershell
   powershell -ExecutionPolicy Bypass -File tool\check.ps1 -Apk
   ```
2. Установка APK на телефон / эмулятор:
   ```powershell
   adb install -r build\app\outputs\flutter-apk\app-debug.apk
   ```
3. Проверка полной истории и ручной записи блюда (ТЗ 8.2):
   - Открыть вкладку «История» — в верхней части экрана видна карточка «Сводка за [месяц]» с количеством приготовленных блюд, количеством новых блюд и лучшим блюдом месяца.
   - Нажать кнопку «Записать блюдо» (FAB внизу справа) — ввести название, выбрать тип блюда, сложность, оценку (звёзды) и заметку. Нажать «Сохранить» — блюдо мгновенно появляется в списке с бейджем «Своё блюдо».
   - Нажать на иконку корзины на любой карточке истории — карточка удаляется, внизу появляется SnackBar «Запись удалена» с кнопкой «Отменить» (таймер 5 секунд).
4. Проверка экрана вкусов, аллергий и исключений (ТЗ 6.4, 7.2):
   - Открыть экран настроек (долгое нажатие на заголовок «Сегодня» $\to$ настройки ИИ $\to$ карточка «Вкусы и предпочтения»).
   - На экране отображаются изученные предпочтения (любимые и нелюбимые признаки, топ оценённых блюд).
   - В блоке «Аллергии» нажать «Орехи», в блоке «Исключения» нажать «Грибы».
   - Перейти на экран «Что есть дома», выбрать картофель, морковь, курицу, грецкие орехи, шампиньоны и нажать «Показать блюда».
   - Убедиться, что блюда с грецкими орехами и грибами полностью отфильтрованы и не появляются в выдаче.
5. Проверка резервной копии без ключей (ТЗ 7.2, Правило 7):
   - Открыть экран настроек $\to$ «Резервная копия».
   - Нажать «Скопировать резервную копию» — JSON копируется в буфер обмена с отображением размера в КБ и сводкой таблиц.
   - Убедиться, что в скопированном JSON отсутствуют ключи GigaChat и любые токены.
   - Вставить JSON обратно или нажать «Восстановить данные» с подтверждением — данные успешно восстанавливаются.
