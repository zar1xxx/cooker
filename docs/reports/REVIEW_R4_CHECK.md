## Замечания

### 1. Вывод `ai_smoke` в отчёте выдуман

В отчёте `REVIEW_FIXES_R4.md` есть строки, которых `tool/ai_smoke.dart` не печатает: «Connecting to LM Studio at…», «Available models (1):», «AI Smoke Test Summary». Настоящий формат вывода другой.

Ревьюер запустил `tool\run_ai_smoke.bat` сам → `docs/reports/last_ai_smoke.txt`:

```
[LM Studio] Server reachable on port 1235! Using model: google/gemma-4-12b-qat
[LM Studio] suggest_dishes query FAILED in 120s: AiException(timeout: Превышено время ожидания ответа)
...
exit 0
```

Кроме того, программа завершилась с кодом 0, хотя проверка не прошла.

R4-01 и R3-08 переоткрыты → R5-01.

### 2. LM Studio не отвечает даже на короткий запрос

`tool\llm_speed.bat` → `docs/reports/last_llm_speed.txt`: запрос «Say OK» на 40 токенов не получил ответа за 120 с (`HTTP 000 TIME 120.0s`).

`lms ps`: в памяти три копии `google/gemma-4-12b-qat`, по 7,15 ГБ каждая, с контекстом 262144 и parallel 4. Вероятно, видеопамяти не хватает и модель работает очень медленно — это предположение, его нужно проверить.

→ R5-02, а также шаг владельца.

### 3. Почему телефон не видел ПК

`docs/reports/last_lmstudio_diag.txt`:

```
TCP    127.0.0.1:1235         0.0.0.0:0              LISTENING
```

Сервер слушает только сам ПК. Кроме того, правила брандмауэра для 1235 нет.

Адрес ПК в домашней сети — `192.168.50.224` (Wi-Fi «ASUS_DO_5G 2», частная сеть).

Прежний `start_lmstudio_server.bat` не перезапускал уже работающий сервер, поэтому `--bind 0.0.0.0` не применялся. Ревьюер переписал bat-файл: теперь он делает `lms server stop` → `start --bind 0.0.0.0` и проверяет через `netstat`, кого слушает сервер.

### 4. Ошибки в `pair_pc` и сканере

- Ключ GigaChat принимается аргументом командной строки, а ввод с клавиатуры не скрыт.
- Без сетевых адресов в QR попадает `127.0.0.1`.
- Кнопка «Открыть настройки» на экране сканера просто закрывает экран.

→ R5-04, R5-05.

### 5. Нет перехода на GigaChat

Если ПК долго не отвечает, запрос не переводится на GigaChat → R5-03.

## Можно ли ставить APK R4

Да, на телефон владельца. Но ИИ с ПК заработает только после двух вещей:
1. сервер слушает сеть, и в брандмауэре открыт порт 1235;
2. LM Studio отвечает быстро (шаг владельца по моделям).
