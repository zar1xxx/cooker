## Ошибки, которые я исправил (не прогнано — R1-01)

| # | Файл | Ошибка | Что было бы на телефоне |
| --- | --- | --- | --- |
| F1 | `lib/main.dart`, `lib/core/ai/gigachat_cert.dart` (новый), `ai_settings_service.dart`, `providers.dart` | **Сертификат Минцифры лежал в assets, но нигде не загружался.** `applyToRouter` вызывался без `certBytes`, `checkGigaChat` создавал `Dio()` без сертификата. В тестах это не видно: там мок-адаптер | В Android нет корня «Russian Trusted Root CA» → TLS к Сберу падает → **GigaChat не работает никогда**, «Проверить связь» всегда «нет», запасного режима нет |
| F2 | `lib/core/ai/pc_discovery.dart` | В `probeHost` не было `connectTimeout` — только send/receive | Запрос к несуществующему IP ждёт системный TCP-таймаут (десятки секунд). Поиск по 254 адресам — **минуты** вместо секунд (сценарий 6 требует ≤ 10 с) |
| F3 | `lib/core/ai/ai_router.dart` | Невалидный JSON дважды от LM Studio → `FormatException` пробрасывался наружу | ТЗ 6.1.1 п. 4: после двух невалидных ответов ПК запрос должен уйти в GigaChat. Слабая локальная модель = нет новых блюд, хотя GigaChat настроен |

Сертификат: PEM, `CN=Russian Trusted Root CA`, срок 2022–2032, SHA-256 `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`. Владельцу — сверить отпечаток с официальной страницей Госуслуг.

## Что сделано хорошо

- `isPrivateOrLocalHost` + запрет `http://` для внешних адресов — ровно как просили, с тестами.
- Очередь запросов GigaChat под один поток Freemium, кэш токена до `expires_at − 60 с`, повтор при 401.
- 284 продукта с иерархией, 125 рецептов без битых ссылок, у всех мясных рецептов есть шаг с таймером.
- Тест-«свойство» планировщика на 20 планах (28/29/30/31 день, разные профили).
- Доступность: шрифт 200 % без переполнений на всех экранах, тесты на это.
- Отдельный DECISIONS на каждое допущение — журнал читается.
