## Как запустить и проверить вручную

1. Сборка проекта и прогон проверок:
   ```powershell
   powershell -ExecutionPolicy Bypass -File tool\check.ps1 -Apk
   ```
2. Установка APK на телефон / эмулятор:
   ```powershell
   adb install -r build\app\outputs\flutter-apk\app-debug.apk
   ```
3. Проверка главного экрана «Сегодня» (ТЗ 7.2):
   - Открыть приложение — открывается экран «Сегодня» (`/today`) с русской датой (например, «Четверг, 5 ноября»).
   - Если блюдо на сегодня не запланировано — отображается карточка пустого состояния с крупными кнопками (56 dp) «Подобрать из того, что есть», «Выбрать блюдо» и «Открыть календарь».
   - Нажать «Выбрать блюдо» — открывается модальная шторка со списком блюд и поиском, выбор любого блюда устанавливает его как блюдо на сегодня в календаре.
   - На карточке блюда отображаются иконка типа, время, сложность и проверка продуктов дома («Все продукты есть дома» или «Не хватает: ...» с кнопкой быстрой замены).
   - Кнопка «Готовить» ($\ge 56$ dp) сразу запускает пошаговый режим приготовления.
4. Проверка Сценария 4 ТЗ 11:
   - Перейти во вкладку «Календарь».
   - Выбрать ближайшую субботу, нажать «Заменить» $\to$ переключить фильтр «Избранные» $\to$ выбрать любимое блюдо (например, «Борщ домашний»).
   - Нажать кнопку «Закрепить» — на карточке и в ячейке субботы появляется иконка замка.
   - Нажать кнопку «Составить план на месяц» — все дни до конца месяца заполняются планом, суббота остаётся неизменной («Борщ домашний» с замком).
   - Выбрать любой другой день и нажать кнопку «Заменить» — выбрать другое блюдо из шторки. День заменяется, план остаётся целостным.
   - Отключить Wi-Fi / ПК — нажать «Составить план на месяц»: генерация моментально выполняется локально из каталога без ошибок и бесконечных спиннеров.
5. Проверка ежедневных уведомлений (ТЗ 7.3):
   - Долгое нажатие на заголовок «Сегодня» $\to$ переход в экран «Настройки ИИ».
   - В блоке «Ежедневное напоминание» включить тумблер и нажать на плитку «Время напоминания» (по умолчанию 10:00) $\to$ открывается диалог выбора времени.
