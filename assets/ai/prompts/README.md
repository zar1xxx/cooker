# Промпты

- `system.md` — системный промпт для всех запросов. Блок `{{#if schema_in_prompt}}` включается для GigaChat (у LM Studio схема идёт в `response_format`).
- `suggest_dishes.md`, `full_recipe.md`, `month_plan.md` — шаблоны user-сообщения.

Плейсхолдеры `{{name}}` подставляет `lib/core/ai/prompts.dart`. Списки — через запятую; пустой список → «нет».
Условные блоки `{{#if x}}...{{/if}}` — простой самописный шаблонизатор (без зависимостей), с тестами.

Файлы копируются в `assets/ai/prompts/` и грузятся в рантайме. Правишь промпт — правь здесь и копируй (или настрой копирование в `tool/check.ps1`).

Ограничение размера: «не предлагать» ≤ 40 названий, история в плане ≤ 30 записей, вкусы ≤ 5 + 5.
