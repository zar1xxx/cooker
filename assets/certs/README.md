# Сертификаты

GigaChat API использует сертификат российского удостоверяющего центра. Нужен корневой сертификат **«Russian Trusted Root CA»** (НУЦ Минцифры).

1. Скачай его с официальной страницы Госуслуг (раздел про сертификаты НУЦ Минцифры) или по ссылке из документации GigaChat (developers.sber.ru → GigaChat API → раздел про сертификаты).
2. Положи сюда как `russian_trusted_root_ca.cer` (PEM или DER — проверь формат и укажи в DECISIONS).
3. В приложении он используется **только** для Dio-клиента GigaChat (см. `skills/ai-integration`).
4. Для `tool/gigachat_ping.ps1` на ПК тот же сертификат надо установить в Windows: двойной клик → «Установить сертификат» → «Локальный компьютер» → «Доверенные корневые центры сертификации».

Файл сертификата — публичный, его можно коммитить.
