# «Что приготовить?»

Мобильное приложение (Flutter, Android): выбираешь продукты, которые есть дома, — получаешь блюда, рецепты и пошаговую готовку. ИИ: LM Studio на домашнем ПК, если он в сети, иначе GigaChat; без сети — встроенный каталог рецептов.

## Для владельца

- **Как запустить исполнителя:** дай ему задание «Прочитай `AGENTS.md` и выполни следующую незакрытую задачу из `docs/TASKS.md`».
- **Где смотреть прогресс:** `docs/STATUS.md` (текущий этап, блокеры, вопросы к тебе) и отчёты в `docs/reports/`.
- **Как проверить этап:** открой отчёт, сверь с условием «Готово, когда» в `docs/TASKS.md`, при желании запусти `tool\check.ps1` сам.
- **Живая версия ТЗ:** https://claude.ai/artifact/3q34dtW9VRUsfcDMQSbVxK (в `docs/TZ.md` — копия от 2026-11-04).

## Что где лежит

```
AGENTS.md              — точка входа для ИИ-исполнителя (правила, порядок чтения)
CLAUDE.md              — ссылка на AGENTS.md (для Claude Code)
docs/
  TZ.md                — техническое задание
  TASKS.md             — задачи по этапам 0–6 с ID и «Готово, когда»
  STATUS.md            — текущий статус, блокеры, вопросы владельцу
  DECISIONS.md         — решения и допущения
  REPORT_TEMPLATE.md   — шаблон отчёта по этапу
  ENV_SETUP.md         — окружение Windows и известные грабли
  INSTALL.md           — черновик инструкции по установке
  reports/             — отчёты исполнителя
skills/                — пошаговые инструкции под типовые работы
spec/
  ai/schemas/          — JSON-схемы ответов ИИ
  ai/prompts/          — системный промпт и шаблоны запросов
  ai/safety_minimums.json — минимальные режимы тепловой обработки
  data/                — перечисления, категории, примеры seed-файлов
  fixtures/ai/         — эталонные ответы ИИ для тестов
tool/                  — check.ps1, проверки LM Studio и GigaChat, брандмауэр
assets/certs/          — сюда сертификат Russian Trusted Root CA
.github/workflows/ci.yml — CI: analyze + test + сборка APK
```
