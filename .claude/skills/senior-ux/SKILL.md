# Интерфейс для бабушки

Главный пользователь — пожилой человек, телефон Android, возможно не самый новый. Каждый экран проверяй вопросом: «Поймёт ли она, что нажать, без подсказки?»

## Обязательно

- Текст ≥ 18 sp, заголовки 24 sp, режим готовки 28 sp. Только через `Theme.of(context).textTheme`, никаких захардкоженных размеров.
- Зона нажатия ≥ 56×56 dp. Между соседними кнопками ≥ 8 dp.
- Контраст текста ≥ 4.5:1 в обеих темах.
- У каждой иконки — подпись текстом. Иконка без слов допустима только как дополнение.
- Одно главное действие на экране — крупная заполненная кнопка. Остальные — второстепенные.
- Любое действие, доступное жестом (свайп), дублируется кнопкой.
- Деструктивные действия (удаление) — мягкие, со snackbar «Отменить» 5 с. Без диалогов «Вы уверены?» с мелкими кнопками.
- Загрузка ИИ не блокирует экран: локальные результаты сразу, новые — подъезжают сверху.
- Ошибки — человеческим языком, без кодов и английских слов. Пример: «Нет интернета, показываю сохранённые рецепты».
- Тексты — только из ARB. Короткие фразы, без жаргона («порции», а не «сервинги»).
- `Semantics` с осмысленными label на всех интерактивных элементах (TalkBack).

## Проверка экрана перед закрытием задачи

1. Шрифт системы на максимум (200 %) — ничего не обрезается, нет overflow.
2. Тёмная тема — всё читается.
3. Виджет-тест: главная кнопка находится по тексту и нажимается.
4. Скриншот в `docs/reports/img/`.

## Чего не делать

- Не прятать важное в меню «три точки».
- Не использовать мелкие чекбоксы — только крупные плитки/переключатели.
- Не показывать настройки ИИ, ключи, адреса на основных экранах.
- Не делать онбординг из нескольких экранов — приложение работает сразу.
